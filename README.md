# Automation Skills

OpenClaw用の自動化スキル集

## 自律提案システム (autonomous-proposal)

ユーザーの行動パターンを自動検出し、スキル化を提案するシステムです。

### 機能

1. **パターン検出エンジン** (#55)
   - 繰り返しパターン検出（3回以上）
   - 複雑度判定（5ステップ以上）
   - エラーパターン検出（3回以上）

2. **ログ収集システム** (#56)
   - Discordログ収集（message tool活用）
   - Obsidianノート解析
   - GitHub Issues監視

3. **スキル生成テンプレート** (#57)
   - スキルひな形生成機能
   - SKILL.md / package.json / index.js 自動生成
   - 必須フィールドのプレースホルダー

4. **提案通知システム** (#58)
   - Discord通知
   - 承認待ちリスト

5. **承認フロー** (#59)
   - リアクションベースの承認
   - 却下オプション

### インストール

```bash
cd skills/autonomous-proposal
npm install
npm run build
```

### 使用方法

```typescript
import { AutonomousProposal } from './dist/index';

const proposal = new AutonomousProposal({
  skillsDir: '/path/to/skills',
  obsidianVaultPath: '/path/to/vault',
  discordChannels: ['channel-id-1', 'channel-id-2'],
  githubRepos: ['owner/repo'],
});

// 実行
const proposals = await proposal.run();

// 保留中の提案を確認
const pending = proposal.getPendingProposals();

// 提案を承認
proposal.approveProposal('proposal-id');
```

### 設定

`config.json`で以下の設定が可能です:

```json
{
  "skillsDir": "/path/to/skills",
  "obsidianVaultPath": "/path/to/vault",
  "discordChannels": ["channel-id-1"],
  "githubRepos": ["owner/repo"],
  "autoGenerate": false
}
```
